# نظام إدارة مزرعة المرفأ

## التشغيل السحابي
1. افتح مشروع Supabase المستخدم لمزرعة ليوا 77.
2. افتح SQL Editor.
3. انسخ محتوى `supabase-setup.sql` وشغّله مرة واحدة.
4. أنشئ مستودع GitHub عامًا باسم `almirfa-farm`.
5. ارفع جميع الملفات الموجودة داخل هذا المجلد إلى جذر المستودع.
6. من Settings > Pages اختر main و /(root).

الرابط المتوقع:
`https://liwa77farm.github.io/almirfa-farm/`

رمز الدخول الافتراضي: `7788`
يمكن تغييره داخل `config.js`.
